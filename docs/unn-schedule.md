# Расписание ННГУ

Сервис `unn-sync` загружает публичное расписание с [rasp.unn.ru](https://rasp.unn.ru/). После запуска он обновляет текущую и следующую недели по московскому времени. Интервал после завершения цикла задаётся через `UNN_SYNC_INTERVAL`, по умолчанию 1 800 секунд. Данные хранятся в PostgreSQL, поэтому кабинет и мобильное приложение читают последнюю успешную копию.

## Привязка групп, преподавателей и корпусов

Для команд нужен запущенный Compose-стенд с применёнными миграциями. Найдите группу по её номеру на сайте.

```sh
docker compose run --rm --no-deps unn-sync python -m attendance.unn_sync catalog group "3824Б1ПИ1"
docker compose run --rm --no-deps unn-sync python -m attendance.unn_sync bind-group 281474976736763
```

`bind-group` создаёт локальную группу с номером ННГУ. Если у студентов уже есть локальная группа под другим названием, передайте её имя через `--local-name`. Их членство и история отметок сохранятся.

Для преподавателей выполните поиск по имени и укажите найденный идентификатор для существующего локального логина.

```sh
docker compose run --rm --no-deps unn-sync python -m attendance.unn_sync catalog teacher "<фамилия>"
docker compose run --rm --no-deps unn-sync python -m attendance.unn_sync bind-teacher "<логин>" <идентификатор>
```

Синхронизация сопоставляет идентификаторы занятий из расписаний группы и преподавателя. Если для пары подходят несколько привязанных преподавателей, она остаётся доступной группе для просмотра. Для регистрации в текущей модели у занятия должен быть один владелец.

Геозона задаётся для существующего локального корпуса с проверенными координатами и радиусом. Второй аргумент — название корпуса из расписания ННГУ до запятой.

```sh
docker compose run --rm --no-deps unn-sync python -m attendance.unn_sync bind-building "<локальный корпус>" "Корпус № 1"
docker compose run --rm --no-deps unn-sync python -m attendance.unn_sync sync
```

Занятие с непривязанным корпусом видно в расписании. Открыть регистрацию можно после настройки геозоны. Учётные записи и принадлежность студентов к группам ведутся в Attendance. Импорт публичного расписания не заменяет вход через университетский портал.

Разовый импорт можно запустить за конкретную неделю, передав `sync --date 2026-11-18 --weeks 1`. Сервис обновляет пары без сессий и скрывает те, которые исчезли из успешно полученного расписания. Он сохраняет занятия с открытой или завершённой сессией вместе с их временем и отметками. При ошибке сайта данные соответствующей недели остаются доступны из предыдущего импорта.
